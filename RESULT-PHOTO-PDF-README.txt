RESULT PHOTO PDF UPGRADE

1. Keep your existing .env file and Supabase project. No database reset.
2. npm install; npm run dev
3. Staff login > Exam Marks / Automatic Result. Generate result.
4. Click Print / Save PDF beside a student. In Chrome print dialog choose Save as PDF.
5. Student photos are private and loaded with signed URLs; upload photo first from Student Management.
6. CSV download remains CSV without embedded photos; use the new PDF action for photo results.
7. No new SQL is required if student photos already work. Existing student-photo SQL syntax typo is corrected in this ZIP for new installations.
